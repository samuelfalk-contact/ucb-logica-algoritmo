# ucb-logica-algoritmo

Resolução de exercícios semanais, algoritmos e estruturas iniciais desenvolvidas em Linguagem C durante as aulas práticas da disciplina de **Lógica de Programação e Algoritmos** na UCB (2º semestre).

## Estrutura

| Pasta | Conteúdo |
|---|---|
| `atividade-03/` | Atividade 3 (exercícios 1 a 4) |
| `atividade-04/` | Atividade 4 (exercícios 1 a 3) |
| `atividade-05/` | Atividade 5 (exercícios 1 a 5) |
| `atividade-06/` | Atividade 6: vetores (notas de alunos e vendas mensais) |
| `n2-desafio-gestao-de-turma/` | Desafio da N2: sistema de gestão de turma com menu, vetores e relatório |
| `estudos-prova-n1/` | Questões resolvidas como estudo para a prova N1 |
| `revisao-n1/` | Revisão geral para a N1 |
| `outros/` | Testes e códigos avulsos |

## Como compilar

```bash
gcc arquivo.c -o programa
./programa
```

Alguns arquivos têm extensão `.cpp` porque foram escritos no Dev-C++, mas o código é em C.
